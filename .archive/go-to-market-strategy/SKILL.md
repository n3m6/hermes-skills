# Go-To-Market Strategy

Deliverable shape: a plan the user can react to tersely (numbered decision points get 'Ok'/'skip' replies), ending with concrete offers to build artifacts. Verdict first, always.

## Method
1. **Ground in shipped reality first**: run the product-teardown skill on the site if not already analyzed. A GTM plan for an unshipped/empty product is fiction.
2. **Verdict first — name the binding constraints.** Usually 1-2 cold starts; everything downstream must serve them. For an orderbook DEX: liquidity cold start (empty book = no traders) + trust cold start ("we hide your orders" from an unknown team invites paranoia). Reach is rarely the real problem.
3. **Position in three layers:**
   - One-line counter-position vs the category leader ("<leader>'s speed, with your cards hidden") — their strength (transparency) reframed as free reconnaissance for predators.
   - Emotional retail story with a QUANTIFIED villain ($2-4B/yr stop-hunting losses, 15-20% victim hit) — numbers are content, not footnotes.
   - A tech-native wedge incumbents can't clone without rebuilding (e.g. confidential execution as the only venue where AI trading agents don't leak their strategy). Also opens an SDK/API distribution channel.
4. **Trust stack that doubles as content** (pre-req for any privacy/security product): publish what makes claims checkable — source + reproducible build (measurement match), independent audits, a verifier UI ("trust math" must be literally clickable), and an explicit threat-model doc that pre-empts the obvious attack ("TEE = house sees everything") before a skeptic thread lands it. Kill site overclaims (hardcoded demo tickers, "100% uptime" pre-launch): one fake-looking artifact poisons the honesty story, and this user's brand IS honesty.
5. **Channel architecture for the AI/social age:**
   - **X = the core loop**: founder-led building-in-public (weekly technical threads), proof-of-product beats claims (live logs, latency charts, verifier screenshots), reply with substance into every relevant viral thread, a recurring content franchise from the product's own data (e.g. "stop-hunt watch"), Spaces with invited skeptics — handling the hard question publicly IS the brand.
   - **Short-form video = retail emotional amplifier**: 30-45s three-act formats (setup: you place the order → villain: bots see it → reveal: they hunt you). Compliance reality: TikTok restricts finance content and has US platform instability — treat TikTok as education/brand that routes to X, mirror everything to YouTube Shorts + IG Reels where crypto attention is durable. Finance-education micro-creators beat crypto macro-influencers.
   - **AI layer**: (a) LLM answers are SEO 2.0 — win the citation game with HTML docs (not just PDFs), schema.org, GitHub org, ecosystem indexes LLMs crawl; test what ChatGPT/Perplexity/Gemini say monthly; (b) AI agents as CUSTOMERS, not just marketing targets; (c) AI for ops volume, human founder voice kept.
6. **Solve the product-specific cold start directly**, don't market around it: exchanges = sign MMs BEFORE public launch, launch 2-4 deep markets not 30 empty ones, seed the book at launch, maker rebates early; the selective-disclosure data feed (aggregates) is the sales tool to MMs — it's why they can quote blind. Institutional/RFQ motion is relationship sales (private beta for funds), not content marketing.
7. **Sequence in gated phases** (verifier/audits → private beta w/ MMs → public launch on few markets → expand) with KPIs matching the constraints: funded-account conversion, live-book depth, MM count + spread vs leader — not vanity volume or follower counts.
8. **End with honest risks + the few numbered questions that change the plan** (token? retail vs institutional wedge? founder identity public? timeline/partners?). Keep the list short — the user answers terse.
